# Task Manager CLI

Java SE 17を使用した、学習用のタスク管理コンソールアプリケーションです。

## 開発目的

- Javaのオブジェクト指向プログラミングを実践する
- クラス設計と責務分離を学ぶ
- コレクション、列挙型、例外処理などを活用する
- Git / GitHubによるバージョン管理を習得する

## 開発環境

- Java SE 17
- Visual Studio Code
- Git / GitHub

## 開発状況

現在はPhase 0（開発環境構築・基本設計）の段階です。

## 開発計画

| Phase | 内容 |
|---|---|
| 0 | 開発環境構築・仕様設計 |
| 1 | タスク登録・一覧表示・終了 |
| 2 | 更新・削除・完了状態管理 |
| 3 | 優先度・期限・検索 |
| 4 | CSV保存・読込 |
| 5 | テスト・リファクタリング |

## コンパイルと実行

プロジェクトのルートフォルダーで実行してください。

```powershell
javac -encoding UTF-8 -d out src/Main.java
java -cp out Main
```

## 設計方針

- UI、業務処理、データ管理の責務を分離する
- Java標準ライブラリを中心に実装する
- 段階的な機能追加を行う

## 備考

本プロジェクトはJavaの学習を目的として開発中です。
